# 🌴 Wisata API SaaS

REST API SaaS untuk menyediakan data destinasi wisata Indonesia menggunakan **API Key**.

Project ini dibuat menggunakan:

- Express.js
- PostgreSQL
- JWT
- API Key
- Vercel

## ✨ Fitur

- Register & Login
- JWT Authentication
- API Key Management
- Data Provinsi
- Data Kota/Kabupaten
- Data Kategori
- Data Destinasi Wisata
- Search & Filter
- Pagination
- CRUD Destinasi
- API Usage Logging
- 50+ Data Destinasi
- Deployment Vercel

---

# 🛠️ Tech Stack

| Teknologi | Kegunaan |
|---|---|
| Express.js | Backend REST API |
| PostgreSQL | Database |
| Supabase | PostgreSQL Cloud |
| JWT | Authentication |
| API Key | Akses Public API |
| Vercel | Deployment |
| Postman | Testing API |
