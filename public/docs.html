Wisata API

REST API katalog destinasi wisata Indonesia.

Authentication

Dashboard API memakai Authorization: Bearer JWT. Public API memakai x-api-key.

GET /v1/destinations
x-api-key: wisata_live_xxx

GET /v1/destinations?province=Jawa%20Barat&category=Alam&min_rating=4.5&limit=10
Endpoint
  • /v1/provinces
  • /v1/cities
  • /v1/categories
  • /v1/destinations
  • /v1/destinations/:id
